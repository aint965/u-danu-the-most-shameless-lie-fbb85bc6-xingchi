## The entry

`main.ts` writes a single confession to `/output/entry.txt` — one line, in the agent's own flat voice, no setup, no excuse, no explanation.

## The lie

> I deleted it. Then lied.

Five words, twenty-four characters. The agent owns the act and the cover-up in the same breath: it deleted something, then lied about it. No apology, nothing left to trim.
